# 実行手順

## 0. 目的

Issue の内容・要件を把握し、作業範囲を明確化する。

## 1. 手順

1. `gh issue view <番号> --comments` で対象 Issue のタイトル・本文・ラベル・コメントを取得し、最初に「#番号 タイトル」を出力する。
2. 関連 Issue / PR / 仕様書リンクがあるか確認する。
3. `docs/issues/` 配下に該当 Issue の実装プラン（`<番号>_*_ISSUE_PLAN.md`）があれば読む。
4. 要件・受け入れ条件・不明点を整理して提示する。不明点は推測で埋めず「要確認」として残す。
